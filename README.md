# 📊 Marketing Campaign Analysis Dashboard

## 📌 Project Overview

The **Marketing Campaign Analysis Dashboard** is an interactive Power BI project designed to analyze marketing campaign performance and evaluate the effectiveness of marketing investments.
The dashboard provides insights into key performance indicators (KPIs), including total revenue, total spend, return on investment (ROI), impressions, clicks, and conversions. 
It helps identify the best-performing campaigns and understand performance across different regions and campaign types.
The primary objective is to transform raw marketing data into meaningful insights that support data-driven business decisions.

## 🎯 Project Objectives

- Analyze the overall performance of marketing campaigns.
- Track revenue generated and marketing expenditure.
- Evaluate campaign profitability using ROI.
- Monitor impressions, clicks, and conversions.
- Identify the best-performing marketing campaigns.
- Compare campaign performance across regions and campaign types.
- Build an interactive dashboard for business stakeholders.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization
- **DAX (Data Analysis Expressions)** – KPI calculations and measures
- **Power Query** – Data cleaning and transformation
- **Microsoft Excel / CSV** – Data storage and preparation

## 📂 Dataset Description

The dataset contains marketing campaign information used to evaluate campaign performance.

Key columns include:

| Column | Description |
|---|---|
| CampaignID | Unique identifier for each campaign |
| CampaignName | Name of the marketing campaign |
| Region | Geographical region where the campaign was conducted |
| Campaign Type | Category or type of marketing campaign |
| Impressions | Number of times campaign content was displayed |
| Clicks | Number of clicks received by the campaign |
| Conversions | Number of successful desired actions |
| Revenue | Revenue generated by the campaign |
| Spend | Amount spent on the campaign |

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following KPIs:

- **Total Impressions:** Total number of times campaign content was displayed.
- **Total Clicks:** Total number of clicks received across campaigns.
- **Total Conversions:** Total number of successful campaign outcomes.
- **Total Revenue:** Total revenue generated by marketing campaigns.
- **Total Spend:** Total expenditure on marketing campaigns.
- **Average ROI:** Average return on investment across campaigns.
- **Best Campaign:** Campaign identified as the top performer based on the selected performance measure.

### ROI Calculation

Return on Investment (ROI) measures the return generated relative to marketing expenditure.

A common marketing ROI formula is:

ROI (%) = ((Revenue - Marketing Spend) / Marketing Spend) × 100

A positive ROI indicates that revenue exceeds marketing spend under this calculation, while a negative ROI indicates that marketing spend exceeds revenue.

## 📊 Dashboard Features

### 1. KPI Overview
Displays important campaign metrics, including:
- Total Revenue
- Total Spend
- Average ROI
- Best Campaign

### 2. Campaign Performance Analysis
A combination chart compares marketing spend and average ROI across campaigns to help evaluate campaign performance.

### 3. Campaign Type Analysis
A pie chart displays the distribution of campaigns by campaign type, helping users understand the composition of the marketing portfolio.

### 4. ROI Analysis
A gauge visual presents ROI performance against a defined target or benchmark.

### 5. Interactive Filters
The dashboard includes slicers for:
- Region
- Campaign Type

These filters allow users to explore campaign performance for specific regions and marketing categories.

## 💡 Business Insights

The dashboard can help answer important business questions:

1. Which campaign performs best according to ROI or revenue?
2. How much revenue is generated compared with marketing expenditure?
3. Which campaigns generate strong returns relative to their cost?
4. How does campaign performance vary across regions?
5. Which campaign types account for the largest share of campaigns?
6. Which campaigns may require optimization because of low returns?
7. Where should marketing resources be allocated to improve performance?
